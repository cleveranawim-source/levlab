# Gowun Batang

Regular (400) and Bold (700), self-hosted under the included SIL Open Font License 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/gowunbatang (downloaded 2026-11-06).
Upstream: https://github.com/yangheeryu/Gowun-Batang

WOFF2 files were losslessly converted from the upstream TTFs with fontTools/Brotli, retaining full glyph coverage and font metadata. The application uses `next/font/local`, `font-display: swap`, and `preload: false` so routes without serif text do not request these fonts. The separate Gangdan Note font is unchanged.
